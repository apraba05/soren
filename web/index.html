The model reads the invoice. The rules decide.

Soren reads a legal invoice, checks it against six billing rules, and pays it only if every rule passes. Everything else goes to a person, with the reasons.

  1. 01ReadGemini extracts the vendor, total, matter and line items.
  2. 02CheckPlain Python rules decide. The model never approves anything.
  3. 03RouteApproved, or queued for a reviewer. Every decision is logged.
